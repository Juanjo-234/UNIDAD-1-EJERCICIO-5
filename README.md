# UNIDAD-1-EJERCICIO-5
Resolución del ejercicio N°5 de la unidad 1 de programación 2.
El programa simula el control de un medidor de energía eléctrica.
Registrando el número identificador del equipo y el histórico de sus lecturas. 
Permite validar que los datos ingresados mantengan coherencia temporal sin registrar valores menores a los previos. Asimismo, actualiza la lectura del medidor cuando se toma una nueva medición del consumo de luz. 
Finalmente, procesa la información almacenada para obtener la diferencia de consumo entre periodos y muestra el estado general del dispositivo por consola.
